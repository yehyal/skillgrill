# Security Policy

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Use [GitHub private vulnerability reporting](https://github.com/yehyal/skillgrill/security/advisories/new) to send a confidential report. Include the affected area, reproduction steps, impact, and a suggested fix when possible. Remove secrets and personal or production data from the report.

This project supports the `main` branch and the latest deployed version only. Older versions may not receive security fixes. The repository's private vulnerability reporting setting must be enabled in GitHub before this channel can receive reports.

For non-security bugs and feature requests, use the repository's structured issue forms.
